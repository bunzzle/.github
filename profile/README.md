<h3 align="center">Email infrastructure you run yourself.</h3>

**[Bunzzle](https://github.com/bunzzle/bunzzle)** is a self-hosted email delivery engine for apps. It delivers straight to your recipients' mail servers. Bun-native, one binary, one SQLite file.

- Site: [bunzzle.com](https://bunzzle.com)
- Install: [docs/install.md](https://github.com/bunzzle/bunzzle/blob/main/docs/install.md)
- Security: [report a vulnerability](https://github.com/bunzzle/bunzzle/security/advisories/new)
